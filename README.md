## Публикация на GitHub Pages

```bash
git remote add origin git@github.com:arman712/amservice.git
git push -u origin main
```

Затем: **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save**.

Через 1–2 минуты сайт будет доступен по адресу
**<https://arman712.github.io/amservice/>**

Дальнейшие правки выкатываются обычным `git push` — Pages пересобирается сам.

> Файл `.nojekyll` уже добавлен. GitHub Pages по умолчанию прогоняет репозиторий
> через Jekyll, а тот игнорирует папки и файлы, начинающиеся с `_` или `.`, и
> пытается выполнять конструкции вида `{{ … }}` в тексте. Пустой `.nojekyll`
> отключает эту обработку. Сейчас в проекте таких файлов нет — это страховка на
> будущее и один пропущенный шаг сборки при каждом деплое.

### Свой домен

Создайте файл `CNAME` с одной строкой (`amservice.am`) и пропишите DNS по
инструкции GitHub Pages. Canonical и OG-ссылки подстроятся автоматически —
`assets/js/main.js` переписывает их, если сайт открыт не с зашитого адреса.

### Локальный просмотр

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

(Просто открыть `index.html` двойным кликом тоже работает — переводы вшиты в JS,
а не грузятся через `fetch`.)

## Как что менять

### Тексты

**Все видимые строки лежат в одном файле — `assets/js/i18n.js`.**

```js
window.I18N = {
  hy: { "hero.title.1": "Ձեր հեռախոսը՝", ... },
  ru: { "hero.title.1": "Ваш телефон —",  ... },
  en: { "hero.title.1": "Your phone,",    ... },
};
```

В разметке строка подключается атрибутом:

```html
<span data-i18n="hero.title.1">Ձեր հեռախոսը՝</span>
```

Армянский текст продублирован прямо в `index.html` — так страница читается
поисковиками и корректно выглядит даже с выключенным JavaScript. Если меняете
армянский текст, поменяйте его **в обоих местах**.

Для атрибутов (`placeholder`, `alt`, `aria-label`) используется
`data-i18n-attr="placeholder:contact.form.name.ph"`.

> Ключи во всех трёх языках должны совпадать. Проверить:
> ```bash
> node -e "global.window={};require('./assets/js/i18n.js');const I=window.I18N,k=Object.keys(I.hy);
> ['ru','en'].forEach(l=>console.log(l,k.filter(x=>!(x in I[l]))))"
> ```

### Цвета, шрифты, отступы

`assets/css/style.css`, блок `:root` в начале — все токены в одном месте
(`--red`, `--blue`, `--surface`, `--radius`, `--container`, `--header-h` …).
Красный и синий взяты пипеткой прямо с логотипа.

### Телефоны

Меняются в трёх местах: ссылки `tel:` в `index.html`, `CONFIG.whatsapp`
в `assets/js/main.js` и `telephone` в JSON-LD в `<head>`.

### Добавить услугу / товар / вопрос

Скопируйте соседний `<li class="card …">` (или `.acc__item`) в `index.html`,
добавьте новые ключи во все три языка в `i18n.js`. Иконки — `<use href="#i-…"/>`
из спрайта в начале `<body>`.

## Что внутри

```
index.html                  вся разметка + структурированные данные (Schema.org)
site.webmanifest            иконки и имя для «добавить на экран «Домой»»
robots.txt / sitemap.xml    для поисковиков
assets/
  css/style.css             один файл стилей, без фреймворков
  js/i18n.js                все тексты, три языка
  js/main.js                переключение языка, меню, табы, аккордеон, анимации
  fonts/                    9 файлов woff2 — шрифты локально, без запросов к Google
  img/                      логотип (SVG), фавиконки, фото магазина, OG-картинка
pictures/                   исходные скриншоты, по которым делался дизайн
```

### Логотип

`assets/img/logo-mark.svg` — векторная реконструкция фирменного знака **AM**.
Геометрия снята попиксельно с аватара Instagram (углы граней, наклоны штрихов),
цвета — пипеткой оттуда же. Знак масштабируется без потерь и одинаково выглядит
на тёмном фоне, чего не даёт исходная картинка с белой подложкой.
Тот же знак встроен в `index.html` как `<g id="lg-am">` и переиспользуется
в шапке и подвале через `<use>`.

### Что умеет страница

* три языка с запоминанием выбора (`localStorage`) и ссылками вида `?lang=ru`
* липкая шапка, схлопывающаяся верхняя строка, подсветка активного раздела
* мобильное меню и нижняя панель с кнопками звонка
* прайс с вкладками по брендам, аккордеон FAQ, анимации появления
* форма → открывает WhatsApp с уже готовым сообщением (бэкенд не нужен)
* Schema.org `MobilePhoneStore` + `FAQPage`, OG/Twitter-карточки, hreflang
* доступность: семантическая разметка, `aria-*`, навигация с клавиатуры,
  видимый фокус, поддержка `prefers-reduced-motion`
* адаптив от 320 px до широких экранов, стили для печати
